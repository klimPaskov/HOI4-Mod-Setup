# 0.8.2 release validation

This patch release fixes first-install blockers found by running the built app
end to end. Its release pull request, the subsequent main checks, and the
annotated v0.8.2 tag workflow are authoritative for their exact revisions and
final publication. This record does not claim signing, native-package, or
publication results before those gates finish.

## Changes since 0.8.1

- **Offline wiki license.** The package now ships paradox_wiki/LICENSE.txt and
  installation validation rejected it, so new installs on Latest stopped before
  applying any file. Non-empty UTF-8 .txt files are accepted.
- **Repair and update after an install.** The wizard sent its default live-testing
  provider instead of the installed one, so a repair added live-testing files.
  This was the cause of the Candidate acceptance (new) and (kaiserreich) failures
  since 0.8.0: all four acceptance jobs pass again.
- **Mods with a fresh git init.** A repository with no commit yet is a complete
  scan instead of Scan incomplete with scan.git.limit.

## Evidence

- Each fix has a regression test; the UI test fails without its fix. Full Rust,
  front-end, lint and all 20 CI checks passed on the merged pull requests.
- Reproduced and verified in the built Windows app with an isolated profile:
  install of a new mod on the latest package, and the git-init scan.
