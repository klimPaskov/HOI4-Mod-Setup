# 0.8.4 release validation

This patch release adds installer metadata. Its release pull request, the
subsequent main checks, and the annotated v0.8.4 tag workflow are authoritative
for their exact revisions and final publication. This record does not claim
signing, native-package, or publication results before those gates finish.

## Changes since 0.8.3

- **Windows installer.** The Apache 2.0 license agreement is a page of the
  installer, and the publisher, copyright and description are filled in. The
  license file is set only in src-tauri/tauri.windows.conf.json because a license
  file on macOS adds a prompt to the disk image that blocks unattended mounting.
  This does not change SmartScreen or Gatekeeper behavior; that needs official
  signing.

## Evidence

- The change merged as #144 with all 20 CI checks green, including the macOS
  Desktop E2E jobs and the Windows installer E2E.
