## Issues corrected during acceptance

The normal Windows environment exposed an older global server on PATH while
the reviewed bootstrap installed into another current-user prefix. Health
and all selected client registrations now bind to the exact `APPDATA/npm`
installation; a missing reviewed wrapper never falls back to PATH. The real
user's npm installation was not changed by the isolated regression.

Linux CI exposed a missing D-Bus development package in the core-only fuzz
job and a platform-only Clippy return warning. The dependency and expression
were corrected. The vault runner selects one exact existing ignored test,
isolates HOME/XDG/D-Bus, and excludes an inherited source adapter in CI.
