# 0.4.0 release candidate validation

Validation completed on Windows on 11 October 2026 without using the shared
desktop. The version was already 0.4.0 in package, Cargo, lock, and Tauri metadata.
This record covers local preparation; no branch, tag, release, or Pages site was
published.

Type checking, frontend lint/build, accessibility checks, Rust formatting,
Clippy with warnings denied, fuzz-target compilation, workflow authority checks,
and secret-pattern checks passed. pnpm audit reported zero vulnerabilities.
Cargo audit reported zero vulnerability advisories, with informational warnings
for transitive unmaintained crates and the Linux-only glib iterator unsoundness;
Linux is not a supported application platform. Those warnings remain visible.

The final Rust run used the repository's four-thread runner and completed in
121 seconds. It keeps every normal test enabled while avoiding process-startup
contention from a thread per logical CPU. A local-source test no longer mutates
the shared source-selection environment while other tests are running.

## Fixes and scope

Fresh planning now follows the resolved manifest's primary-environment default;
recorded legacy state retains its Codex fallback. Added regressions cover both
paths, public-layout migration, modified-file preservation, removal rollback,
and Live Tools interruption/failure checkpoints. Maintenance test preparation
now binds adapted hashes even for skipped files, matching the real planner.

Release curation retains combined platform SBOMs/notices as internal evidence;
it previously discarded the merged output. Updater signer CLI pins match the
locked version. SBOM generation creates its output directory. Stable release
gates include dependency audits. Documentation, Pages copy, screenshots,
third-party notices, and seven owning skills were refreshed. Historical personal
paths were replaced with placeholders; runtime configuration contains no
hardcoded personal profile. Synthetic Windows/redaction fixtures remain.

No schema or migration format changed. Production credential/authentication and
transaction sequencing did not change. Security, backup, checksum, review, and
rollback gates remain intact. New isolation is compiled only into tests. Native
Windows/macOS support was not expanded. Transaction, platform/release,
documentation, and skill-maintenance handoffs were reviewed by the parent.

The skill ownership check maps changed planning, source, transaction, testing,
release, scanner, and screenshot workflows to their updated owning skills;
adjacent instructions use the same stable commands and accepted defaults.
