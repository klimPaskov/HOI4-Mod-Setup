# 0.9.3 release validation

This release moves the app-owned Meshy launcher to the Meshy MCP 0.6.9 runtime and ships the build and documentation changes merged since 0.9.2. Its release pull request, the subsequent main checks and the annotated v0.9.3 tag workflow are authoritative for their exact revisions and final publication. This record does not claim signing, native-package or publication results before those gates finish.

## Changes since 0.9.2

- **Meshy MCP 0.6.9 (#165).** The launcher accepts only the exact 0.6.9 runtime: 3,956 files, tree SHA-256 `b322d0b8a4ad03f3f0c4840462c517b79fa41ec44473a5800652c005dab6d082`. The new runtime adds `texture_model` to Image to 3D and Multi-Image to 3D and Meshy N1 retexturing. Its dependency lock differs from 0.6.7 only in the Meshy entry, and its environment reads are the same set, so the pinned child environment is unchanged. A project on the 0.6.7 runtime needs **Repair**. The kit moves its Meshy lock in klimPaskov/Agentic-HOI4-Modding#76, merged after this release.
- **Rust 1.90 and Tauri 2.12 (#164)**, with the other crate and npm updates.
- **The azure/login action is pinned to the verified v3.1.0 release commit (#163).**
- **The README describes every tool Setup installs at the same depth (#162).**

## Evidence

- **#165:** all 20 CI jobs were green on its last revision before the merge.
- **Local source gates on Windows, on the #165 revision (main after the merge):**
  - pnpm: install (frozen lockfile), lint, typecheck, `test` (280 frontend tests), `test:manifest`, `test:release-assets`, `test:workflows`, `validate`, `validate:secrets`, `test:rust` (943 passed, 16 ignored) and `audit --audit-level high`;
  - cargo: `fmt --check`, `clippy --workspace --all-targets --all-features -D warnings`, the fuzz build check and `cargo audit`.
- **Meshy runtime review:** a `dist/` diff of 0.6.9 against 0.6.7 found no new network host, child process, file write or import. A live `tools/list` of the 0.6.9 runtime (initialize and tools/list only, no key) returned 28 tools.

## Not covered here

- `test:e2e`, `test:a11y`, `test:scratch-live` and `test:offline` were not run locally. The Desktop E2E jobs on CI cover the built app on Windows, macOS and Linux.
- Signed native packages, notarization and updater replacement are left to the tag workflow and its jobs.
- No paid Meshy call was made through the new launcher before the release. The first one is the kit's next 3D unit run.
