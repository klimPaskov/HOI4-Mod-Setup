# 0.8.5 release validation

This patch release lets Setup read the kit's renamed wiki folder. Its release
pull request, the subsequent main checks, and the annotated v0.8.5 tag workflow
are authoritative for their exact revisions and final publication. This record
does not claim signing, native-package, or publication results before those
gates finish.

## Changes since 0.8.4

- **Wiki folder.** The kit renames `paradox_wiki/` to `hoi4_wiki/`. A manifest
  may declare either destination, and an install or update treats both names as
  the wiki. An installed project that still has `paradox_wiki/` moves to the
  new folder: pages the user did not edit are removed from the old folder, an
  edited page is kept and flagged for review, and the managed `.gitignore`
  block lists both folders. Released 0.8.4 and older builds reject a manifest
  with any other wiki destination, so this release has to be out before the kit
  publishes the new name.

## Evidence

- The change merged as #146 with all 20 CI checks green, including the macOS
  Desktop E2E jobs, the Windows installer E2E and the candidate acceptance jobs.
  One candidate acceptance job failed once on a Windows temporary folder
  cleanup (ENOTEMPTY) and passed on rerun.
- Migration tests: an unedited old folder is replaced, and an edited page is
  kept.
