# 0.7.1 release validation

This patch release turns on the free setup assistant (a first run needs no
account, key, or sign-in) and fixes what live testing of its relay found. Its
release pull request, the subsequent `main` checks, and the annotated `v0.7.1`
tag workflow are authoritative for their exact revisions and final publication.
This record does not claim signing, native-package, or publication results
before those gates finish.

## What live testing of the relay found

The maintainer deployed the relay with `scripts/setup_free_assistant.mjs`.
Every request then answered `502 The free assistant could not reach its model`
in 33 ms, although the same handler returned the expected result when run in
Node with a dummy key.

1. The upstream call used `redirect: "error"`. Node accepts it; the Cloudflare
   Workers runtime rejects it at once. Unit tests with a mocked `fetch` could not
   see it. The relay now uses `manual` and refuses a redirect explicitly, and a
   test asserts that only Workers-accepted modes are used.
2. With that fixed, OpenRouter answered HTTP 404 `Provider returned error`. The
   configured model's only host had status -5 and 0% uptime over 30 minutes.
   The free assistant and the OpenRouter route now default to
   `nvidia/nemotron-3.5-super-vl:free` (structured output, 1M context), and the
   relay lets OpenRouter fall back to `xingchen-agi/xing4.0-29b-a4b:free` and
   `dots-studio/dots-3-note-preview:free`. A refusal now carries the provider's
   short reason, which is how the cause was found.

## Evidence

- Deployed relay, real requests: a plain request returned `OK` in 1.7 s; a
  `json_schema` request returned valid JSON in 13 s.
- Release build from the merged source on a fresh profile (Windows): the welcome
  screen defaulted to **Free model** with no sign-in, key, or setup; importing a
  small existing mod and choosing **Review with Free model** produced an
  accurate review (name, project ID, namespace and prefix, localisation
  encoding, missing thumbnail) in 65 s. The Claude route took 16 s on the same
  mod through the user's signed-in Claude Code.
- Pull requests 120 to 122 passed every required check and the acceptance runs.
  Unit and browser tests assert the free default (own test file) and keep the
  Claude-default tests on a no-relay configuration.

## Not covered by this record

- The free model is shared: OpenRouter allows 50 requests a day to an account
  without purchased credits (1,000 with $10 of credits), and a setup uses one to
  three. When the limit is reached the app says so and offers another assistant.
- Free models change; the relay's fallback list and `relay/README.md` say how to
  check a model's host before changing it.
- Native macOS and Linux behaviour, the updater from 0.7.0, and real Claude and
  Codex sign-in on those systems were not driven by hand. A macOS test prompt
  and a fresh-clone workflow for fixes are prepared separately.
- Signing, notarization, native package smoke tests, and publication are the tag
  workflow's gates and are recorded by that run.
