# 0.7.0 release validation

This minor release collects the app review of 2026-10-24
([record](2026-10-24-app-review.md)), the free setup assistant and OpenRouter
sign-in, the description wand, the web edition's existing-mod parity, and the
server-usable service facade merged before it. Its release pull request, the
subsequent `main` checks, and the annotated `v0.7.0` tag workflow are
authoritative for their exact revisions and final publication. This record
does not claim signing, native-package, or publication results before those
gates finish.

## Changes since 0.6.3

- First install and recovery: a missing Python for HOI4 Agent Tools is shown
  and blocks the install before any file is written; recovery states what
  stopped setup; Undo also removes folders the install created.
- Existing mods: the mod's own valid `descriptor.mod`, `thumbnail.png`, and
  `README.md` are kept by default; installed subagents are not reported as
  malformed; setup's own files are left out of the project profile.
- Update, repair, and merge: no-change updates ask nothing and rewrite
  nothing; **Merge** is a line-based three-way merge; a merged or kept edit
  stays safe at the next update and no longer blocks readiness.
- **Remove components** applies, runs only the reviewed image cleanup, and
  keeps the mod's own files.
- Setup package verification reads on several threads.
- Dependencies: `rustls-webpki`, `webpki-roots`, `webpki-root-certs`, and
  `vite` are at their patched versions, so both audits pass.

## Evidence on the merged commit

Pull request 111 passed every required check and the three candidate
acceptance runs: Rust on Windows, macOS, and Ubuntu; frontend; the four
desktop end-to-end jobs; fuzz target compilation; the wasm32 core; the web
edition; the service facade without the OS keyring; `cargo-audit`;
`npm-audit`; repository integrity; and secret patterns. Locally, on Windows
release builds, create, import, reimport, update, repair, remove, interrupted
install, and Undo were run on real Workshop mods; the counts and findings are
in the app review record.

## Not covered by this record

- Source pinning (**Specific commit**, **Release**) was not driven live for this record; it was checked afterwards on a release build (plans resolved to the exact revision, nothing applied), and the one message fix it led to is in the next release.
- Claude and Codex account sign-in, the free relay (not deployed), macOS and
  Linux behaviour of the native app, and the updater were not exercised by
  hand.
- Signing, notarization, native package smoke tests, and publication are the
  tag workflow's gates and are recorded by that run, not here.
