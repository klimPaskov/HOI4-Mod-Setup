# 0.8.3 release validation

This release carries the reviewed Meshy MCP runtime update. Its release pull
request, the subsequent main checks, and the annotated v0.8.3 tag workflow are
authoritative for their exact revisions and final publication. This record does
not claim signing, native-package, or publication results before those gates
finish.

## Changes since 0.8.2

- **Meshy runtime 0.6.7.** The app-owned Meshy launcher accepts only the
  reviewed @meshy-ai/meshy-mcp-server 0.6.7 runtime (3,954 files) and always
  defines ProgramFiles and ProgramFiles(x86) for the child, so a project .env
  cannot choose the slicer path. Projects set up with the 0.6.2 runtime need
  Repair.
- **Kit pairing.** Latest mode resolves the kit default branch, which contains
  the matching 0.6.7 runtime lock (Agentic-HOI4-Modding 2d645fb or later).
