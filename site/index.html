HOI4 Mod Setup

Prepare your HOI4 mod for AI-assisted development

Start a new mod or set up one you already have. Install project instructions, modding skills, specialist subagents, tools, and an offline wiki, then open your coding client.

What you get

Project instructions

Modding guidance adapted to your mod and coding client. Choose any supported client and add the others you use.

Image generation

Choose a main image provider, add optional providers, and change them later. API keys stay in the Windows, macOS or Linux credential store.

HOI4 workflow skills

Events, decisions, focus trees, scripted GUIs, assets, frame animation, save inspection, and more, in .claude/skills.

Specialist subagents

Planners, auditors, and asset workers for the different parts of your mod.

HOI4 Agent Tools MCP

Build focus trees, events, decisions and worlds. Preview windows and maps, fix scripts and balance AI choices with your agent.

Optional workflows

3D models with Meshy and Blender, Super Events, ComfyUI portraits, and live testing through Clausewitz MCP by smerss or experimental HOI4 Live Tools.

Setup you can maintain

Update the modding package, repair missing setup files, change your coding clients, or add workflows later.

How it works

  1. Start a project. Create a new mod from a short description or import an existing one. Your chosen setup assistant helps prepare its details.
  2. Review the identity. Confirm the project ID, script prefix, tags, and folders the assistant suggests.
  3. Pick your clients. Choose any supported primary coding client, then add other clients you use.
  4. Choose an image provider. Pick a main image provider, add optional providers, or change the choice later.
  5. Choose components and workflows. Select your modding tools, offline wiki, and optional workflows.
  6. Review and install. Review the files and folders to add or update, then follow installation progress.
  7. Open the mod. Open the prepared project in your primary coding client.

Install on Linux

Choose the AppImage or Debian package for an x86-64 desktop. Mark the AppImage executable and open it, or install the Debian package using your package manager. Ubuntu 22.04 and 24.04 are the test platforms. See the Linux install guide for runtime dependencies, Steam paths, credential storage and updates.
