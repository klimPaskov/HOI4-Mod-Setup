HOI4 Mod Setup

Prepare your HOI4 mod for AI-assisted development

Start a new mod or set up one you already have. Install project instructions, modding skills, specialist subagents, tools, and an offline wiki, then open your coding client.

Download for Windows macOS and all releases Quick start Video tutorials

What you get

Project instructions

Modding guidance adapted to your mod's name, prefix, and game folder, with Claude Code as the default client and packages for Codex, Cursor, Qoder, and OpenCode.

HOI4 workflow skills

Events, decisions, focus trees, scripted GUIs, assets, frame animation, save inspection, and more, in .claude/skills.

Specialist subagents

Planners, auditors, and asset workers for the different parts of your mod.

HOI4 Agent Tools MCP

Build focus trees, events, decisions and worlds. Preview windows and maps, fix scripts and balance AI choices with your agent.

Optional workflows

3D models with Meshy and Blender, Super Events, ComfyUI portraits, and live game testing through HOI4 Live Tools.

Setup you can maintain

Update the modding package, repair missing setup files, change your coding clients, or add workflows later.

How it works

  1. Start a project. Create a new mod from a short description or import an existing one. Claude, signed in through your own Claude Code, helps prepare its details by default.
  2. Review the identity. Confirm the project ID, script prefix, tags, and folders the assistant suggests.
  3. Pick your clients. Claude Code is the default primary environment; choose another primary or add Codex, Cursor, Qoder, or OpenCode if you use them.
  4. Choose components and workflows. Select your modding tools, offline wiki, and optional workflows.
  5. Review and install. Review the files and folders to add or update, then follow installation progress.
  6. Open the mod. Open the prepared project in your primary coding client.
