HOI4 Mod Setup

Agentic Hearts of Iron IV modding, set up in minutes

A desktop wizard that prepares a new or existing Hearts of Iron IV mod for AI-assisted development. It installs project instructions, HOI4 workflow skills, specialist subagents, the HOI4 Agent Tools MCP server, and an offline Paradox wiki, with Claude Code as the primary environment and generated copies for Codex, Cursor, Qoder, and OpenCode.

What you get

Claude-first instructions

A complete CLAUDE.md adapted to your mod name, prefix, and game folder, plus its AGENTS.md copy for other clients.

HOI4 workflow skills

Events, decisions, focus trees, scripted GUIs, assets, frame animation, save inspection, and more, in .claude/skills.

Specialist subagents

Auditors, planners, and asset workers with fixed model tiers: Opus for the improvement loop planner, Sonnet for five demanding roles, Haiku for the rest.

HOI4 Agent Tools MCP

Focus, event, technology, GUI, map, probability, and documentation routes, installed at a verified version and registered for each client.

Optional workflows

3D models with Meshy and Blender, Super Events, ComfyUI portraits, and live game testing through HOI4 Live Tools.

Safe by design

Every change is shown in a dry run, applied as a transaction with backup and undo, and later updated, repaired, or removed from the same app.

How it works

  1. Start a project. Create a new mod from a short description or import an existing one. Claude, signed in through your own Claude Code, analyses it by default.
  2. Review the identity. Confirm the project ID, script prefix, tags, and folders the assistant suggests.
  3. Pick your clients. Claude Code is the primary environment; add Codex, Cursor, Qoder, or OpenCode if you use them.
  4. Choose components and workflows. Required items stay selected; optional workflows never block the core setup.
  5. Review and install. Inspect every file in the dry run, then install with live progress and safe recovery.
  6. Open the mod. Start Claude Code in the prepared project straight from the Ready screen.
